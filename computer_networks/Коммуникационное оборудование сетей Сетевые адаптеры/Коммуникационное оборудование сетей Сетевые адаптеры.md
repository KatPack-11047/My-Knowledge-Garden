## Что такое сетевой адаптер?
![[Pasted image 20260207192743.png]]
**Сетевой адаптер (Network Interface Card, NIC)** — аппаратное устройство, обеспечивающее подключение компьютера к сети и обмен данными.

- **Другие названия:**
	- сетевая карта, Ethernet-адаптер, LAN-адаптер.

>	**Основные задачи адаптера** 
>    
>	**Преобразование данных** — из параллельного формата ПК в последовательный для передачи по сети        
>
>	**Формирование кадров** — добавление MAC-адресов, контрольных сумм
>
	**Управление доступом к среде** — реализация протоколов CSMA/CD (Ethernet), CSMA/CA (Wi-Fi)
	**Буферизация данных**  — временное хранение кадров при приёме/передаче

---
## Функции сетевого адаптера

![[Pasted image 20260207193555.png]]
- **Физическая адресация:** каждый адаптер имеет уникальный **MAC-адрес (48 бит)** для идентификации в локальной сети.
![[Pasted image 20260207193602.png]]
- **Передача/прием:** преобразование бит в электрические/оптические сигналы и проверка целостности через CRC.
![[Pasted image 20260207193607.png]]
- **Управление потоком (Flow Control):** регулировка скорости для предотвращения переполнения буфера.

## Характеристики сетевых адаптеров

#### Скорость передачи

|**Стандарт**|**Скорость**|**Применение**|
|---|---|---|
|Ethernet|10 Мбит/с|Устаревший|
|Fast Ethernet|100 Мбит/с|—|
|Gigabit Ethernet|1 Гбит/с|Современный стандарт|
|Высокоскоростные|10 – 100 Гбит/с|Серверы и ЦОД|

#### Другие параметры

- **Интерфейсы:** PCI, PCIe, USB, M.2.
    
- **Режимы:** Полудуплекс / Полный дуплекс.
    
- **Технологии:**
    
    - **Wake-on-LAN (WoL):** удаленное включение ПК.
        
    - **VLAN, QoS:** поддержка корпоративных сетей.

## Классификация 

#### ***По типу подключения***

1. **Проводные:**
    
    - **Ethernet (RJ-45):** витая пара.
        
    - **Fiber (SFP/SFP+):** оптоволокно.
        
    - _Плюсы:_ стабильность, низкая задержка. _Минусы:_ зависимость от кабеля.
        
2. **Беспроводные:**
    
    - **Wi-Fi (802.11):** беспроводная ЛВС.
        
    - **Bluetooth:** малые расстояния (до 100 м).
        
    - _Плюсы:_ мобильность. _Минусы:_ помехи, ниже безопасность.
        

#### ***По форм-фактору***

- **Встроенные (onboard):** интегрированы в материнскую плату.
    
- **PCI / PCIe карты:** для серверов или апгрейда.
    
- **USB-адаптеры:** портативные, но медленнее PCIe.
    
- **M.2 / NGFF:** компактные модули для ноутбуков (Wi-Fi + Bluetooth).

## Драйверы сетевых адаптеров

**Драйвер** — программное обеспечение, которое позволяет операционной системе взаимодействовать с сетевым адаптером
![[Pasted image 20260207193959.png]]
- **Основные задачи драйвера:** 
	•Инициализация адаптера  — настройка при загрузке ОС
	
	•Управление передачей/приёмом — формирование кадров, контроль ошибок
	
	•Обработка прерываний — уведомление ОС о событиях (приём кадра, ошибка)
	
	•Настройка параметров  — скорость, дуплекс, MAC-адрес, Wake-on-LAN

>⚠️**Важно:** Некорректные драйверы приводят к потере пакетов и отказу сети; необходимо обновление с сайта производителя.
    

## Популярные производители

- **Intel:** корпоративный сектор, серверы.
    
- **Realtek:** массовый сегмент, встроенные решения.
    
- **Broadcom / Mellanox (NVIDIA):** высокопроизводительные решения для ЦОД и ИИ.
    
- **Qualcomm Atheros:** чипсеты для ноутбуков и Wi-Fi.
    
- **TP-Link / D-Link:** домашние пользователи.
