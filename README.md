# 🧠 Knowledge Garden: Study Notes & Insights

Welcome to my personal knowledge repository! This space is dedicated to efficient, structured, and simple note-taking.

## 🎯 Purpose

This repository was created to streamline the process of capturing educational materials, articles (from platforms like **Habr**), and lecture notes. Everything is organized into a clean, searchable format to help turn information into long-term knowledge.

## 🛠 Tools I Use

- **[Obsidian](https://obsidian.md/):** The core engine of this repository. It allows for a "second brain" approach using linked notes.
    
- **Markdown:** All notes are written in `.md` for maximum portability, readability, and future-proofing.
    
- **Git:** For version control and keeping my learning history safe.
    

## 📂 What’s Inside?

- **Habr Digests:** Compressed insights from top tech articles.
    
- **Lecture Notes:** Structured summaries from university or online courses.
    
- **Web Clippings:** Curated content from around the web, cleaned up for easy reading.
    
- **Interlinked Concepts:** Using Obsidian’s `[[wikilinks]]` to connect related topics.
    

---

### 💡 Why Markdown + Obsidian?

> "Writing is thinking on paper."

By using Markdown, I ensure that my notes are not locked into a proprietary format. Combined with Obsidian's graph view, I can see how different subjects—from coding to philosophy—overlap and support each other.

### 🚀 Getting Started

If you're exploring this repo:

1. **Clone it:** `git clone https://github.com/KatPack-11047/My-Knowledge-Garden

3. **Browse:** Check the `Archive` or `Inbox` folders for the latest updates.
